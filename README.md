# WorldDownloadX

Download multiplayer Minecraft worlds into singleplayer worlds

## Usage

### Commands

`wdlx:start <world_name>` - start WDL
`wdlx:stop` - stop WDL

## Local Development

### Build

`./gradlew build`

the output jar will be at: `build/libs/WorldDownloadX-<version>.jar`

### Local Dev Run

`./gradlew run`
